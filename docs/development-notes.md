# Журнал розроблення і перевірки

Тема: варіант №1 нової методички — науково-популярний новинний портал. Початковий проєкт автошколи збережено окремо; він не є вихідним кодом цього порталу.

## Реалізовані рішення

ASP.NET Core MVC з окремим сервісом редакційного процесу; PostgreSQL 17.11 через Npgsql і EF Core; InitialSchema migration; Identity з Author, Editor і Reader; Bootstrap 5.3.8; звичайний закодований текст; локальні SVG; історія знімків і порівняння LCS до 200 рядків. Створення захищено унікальним request key, зміни — Version concurrency token. Доступ до чернеток обмежено власником або редактором.

## Участь інструментів

Для підготовки коду, тестових сценаріїв, діаграм і текстових пояснень використовувався генеративний асистент. Компіляція, застосування міграцій, HTTP-запити, SELECT, модульні та браузерні тести фактично виконувалися. Цей журнал не приписує студентові непідтверджений відсоток самостійної роботи. Автоматизоване створення пояснень не є доказом самостійного проведення досліджень зовнішніх наукових тем.

## Знайдений дефект

При обробці відхиленого POST початковий StatusCodePagesWithReExecute повторно використовував POST на GET-only маршруті помилки. Кінцевий статус ставав 405 замість очікуваного 400. Застосовано пряме безпечне формування статусної сторінки; фінальний HTTP-набір підтвердив правильний 400 без зміни даних.

В процесі підготовки також уточнено тестові очікування: enum зберігається текстом, вхід без returnUrl веде на головну, а ім’я кнопки входу містить стрілку. Вони є виправленнями тестової автоматизації, не прихованими бізнес-дефектами.

## Фактичні докази

- `evidence/unit-tests.trx`: 13 модульних перевірок, 0 невдалих.
- `evidence/http-results.json`: 41 перевірка реального HTTP/PostgreSQL, 0 невдалих, включно з 50 послідовними запитами каталогу.
- `evidence/persistence.json`: читання того самого матеріалу після нового процесу backend.
- `evidence/browser-results.json`: 8 перевірок headless Edge, ширини 1440/390px, 0 pageerror.
- PNG: фактичний HTML/CSS продукту.
- `evidence/video-facts.json`: безперервний сценарій 205 секунд, власний backend і справжній SQL, а не запис робочого столу.

E2E-дані з префіксом `E2E-` очищено після перевірок лише в окремій локальній навчальній БД. Демо-стаття з відео збережена окремо. Самі докази не змінювалися для вигляду успіху.

## Межі

Перевірене середовище — нативний Windows, .NET SDK 10.0.403, PostgreSQL 17.11. Dockerfile/Compose підготовлені, але тут не виконані через відсутність Docker. Не проводилися production deployment, зовнішній аудит, великий конкурентний load test або повний аудит WCAG. Жоден із цих пунктів не позначено як успішний тест.
