# Версія подання v1.0.2

ScienceLine — науково-популярний новинний портал для варіанта 1, ASP.NET Core MVC та PostgreSQL. Від v1.0.1 додано відтворювані досліди обсягу БД 100/1 000/10 000 статей, шість конкурентних навантажувальних прогонів, браузерні заміри та визначений набір перевірок доступності. Прикладний C#-код і правила предметної області не змінені від перевіреної v1.0.0.

Базові докази: 13 модульних, 41 HTTP- та 8 браузерних перевірок, окреме читання після перезапуску. Додатковий експеримент 29.10.2026: 45 141 виміряний запит, 0 помилок; сирі зразки, умови, пороги, плани запитів та ресурси збережено у docs/evidence/quality. Відтворення — scripts/run-quality.ps1 і README. Дані експерименту синтетичні, ізольована БД не замінює робочу.

Оновлені пояснювальна записка і протокол відповідають цій версії. MP4 тривалістю 204,84 с демонструє незмінений бізнес-процес. Звіт і відео передаються окремими файлами. Docker не запускався; польовий INP та повна сертифікація WCAG не заявляються.

Чинні паролі, локальні ключі, БД, SDK, кеші, журнали приватного середовища й браузерні профілі не публікуються. Власні параметри запуску створюються за README.
