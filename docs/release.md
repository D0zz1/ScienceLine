# Версія подання v1.0.3

Від v1.0.2 оновлено відеодемонстрацію: посимвольний ввід 105 мс, паузи між полями й переходами, справжній повний цикл автора й редактора та PostgreSQL після перезапуску. Тривалість — 330,2 с (5 хв 30 с). Запис автоматизований, безперервний, на окремій навчальній БД. Таймкоди записки та показник у протоколі відповідають новому MP4.

Прикладний C#-код, міграції, правила та результати базових тестів не змінено: 13 модульних, 41 HTTP-, 8 браузерних перевірок і окрема перевірка перезапуску. Збережені додаткові досліди обсягу, навантаження, frontend та індексу/CSS від v1.0.2.

Код публікується без чинних паролів, ключів, БД, SDK та кешів. Записка, протокол і MP4 передаються окремими файлами з кодом. Docker, польовий INP і повний WCAG-аудит не заявляються як виконані.
