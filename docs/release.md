# Версія подання v1.0.1

Працездатний портал ScienceLine для варіанта1, ASP.NET Core MVC та PostgreSQL. Версія v1.0.1 уточнює стрілки діаграм, знімки екранів і сценарій відео, щоб доданий абзац і збережений текст були видимі безпосередньо в кадрі. Прикладний C#-код і правила предметної області не змінені від перевіреної v1.0.0.

Докази локального виконання: 13 модульних, 41 HTTP-перевірка реальної PostgreSQL, 8 браузерних перевірок та окреме читання після перезапуску. Фінальна MP4-демонстрація має тривалість близько205 секунд. Звіт і відео передаються як окремі файли разом із вихідним архівом; вони не є прихованими залежностями запуску.

Публічний код не містить чинних паролів, локальних ключів Data Protection, бази даних, SDK або браузерних профілів. Для нового запуску створюються власні параметри за README.
